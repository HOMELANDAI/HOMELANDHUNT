# Twitch & Maestro.tv Strategy

## Broadcast Thesis

Homeland Hunt should be designed as both a playable game and a watchable recurring competition. Clue discovery, NPC conversations, route decisions, time pressure, object activations and leaderboard movement all create broadcast moments.

## Twitch

### Best Role

Broad live discovery, community interaction and social FOMO.

### High-Interest Content

- live monthly hunts;
- player POVs;
- clue-solving commentary;
- NPC/CPC conversations;
- live leaderboard movement;
- chat predictions and polls;
- Easter-egg discoveries;
- February/December special-event hype;
- post-event analysis.

### Tier Strategy

Avoid hard-coding current Twitch subscription prices into product logic. Instead define HAI access classes that can map to whatever Twitch monetization features are available at launch.

Suggested access ladder:

- public live broadcast;
- supporter replay/BTS access;
- premium alternate POV/analysis access;
- top supporter special-event or archive benefits where platform rules permit.

### Content Quality & Viewer Interest

**Projected fit: 9.5/10 if production is readable and the game creates frequent decision moments.**

The main risk is downtime. Long travel sequences or puzzles that are opaque to viewers will hurt retention. Broadcast UI should continuously communicate the active clue, timer, inventory, player ranking and stakes without exposing protected answers.

## Maestro.tv

### Best Role

Premium owned viewing destination and interactive companion experience.

Potential features:

- Mixcast View;
- selectable POVs;
- interactive overlays;
- premium replays;
- Legacy/member gates;
- NPC dossiers;
- clue timelines;
- inventory/object telemetry;
- sponsor integrations;
- post-event deep dives;
- annual championship/retreat content.

### Content Quality & Viewer Interest

**Projected fit: 10/10 for the premium layer** because Homeland Hunt generates multiple simultaneous information streams that benefit from an interactive viewing interface.

## Spectator Participation

Spectators can influence non-integrity-critical elements:

- choose optional side quests;
- vote on cosmetic/environmental changes;
- unlock public hints;
- predict outcomes;
- select featured POVs;
- award fan-voted recognition.

Audience mechanics must not allow paying viewers to unfairly determine cash-prize outcomes.

## Broadcast UI Minimum

Every live view should expose:

- current objective;
- remaining time;
- player/team identity;
- rank;
- visible inventory;
- object cooldown/status;
- map/region context;
- event purse/award context;
- clear HAI branding.
