# Development Roadmap

## Phase 0 — Rules Lock

Define before coding:

- exact monthly contest rules;
- meaning of each entry tier;
- "2 hours prior return on buy in" rule;
- prize funding and payout logic;
- Legacy benefits;
- Shield/Helmet/Anchor/Timepiece canonical effects;
- allowed sabotage;
- NFT vs non-NFT equivalents;
- geographic/age eligibility.

## Phase 1 — Vertical Slice

Build one region with:

- 8–12 players;
- 5–8 lyrical clues;
- one artist-style original NPC (not a real-person likeness for prototype);
- four core objects;
- one found map + one premium map;
- timer;
- leaderboard;
- spectator overlay;
- no real-money prize requirement.

Goal: prove that watching players reason is entertaining.

## Phase 2 — Closed Competitive Beta

Add:

- account progression;
- multiple clue chains;
- anti-cheat logging;
- inventory economy;
- tournament administration;
- Twitch broadcast test;
- Maestro interactive prototype;
- synthetic/virtual rewards.

## Phase 3 — Economy Pilot

After legal/product review:

- paid entry pilot where permitted;
- HAI digital asset minting;
- limited functional NFT test;
- Legacy access pilot;
- sponsor-funded prizes;
- measured secondary-market observation rather than projected assumptions.

## Phase 4 — AI Character Expansion

- persistent memory;
- multi-agent NPC coordination;
- companion object agents;
- licensed artist pilots;
- ACE-compatible or equivalent character runtime evaluation.

## Phase 5 — Spatial Hunt

- mobile AR proof of concept;
- XR-glasses client;
- spatial anchors;
- physical HAI Hunt zone;
- resort/festival/excursion pilot;
- remote Twitch/Maestro spectator layer.

## Key Success Metrics

- clue completion rate;
- average decision moments per minute;
- viewer retention;
- player return rate;
- monthly contest repeat participation;
- Legacy conversion;
- tool purchase without pay-to-win complaints;
- NPC interaction length/return rate;
- stream chat participation;
- prize-event conversion;
- fraud/cheat incidence.
